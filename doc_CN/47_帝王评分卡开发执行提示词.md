## 一、总约束提示词

以下整段可作为每轮开发的固定前言，再追加本轮指定的里程碑。

```text
你正在开发 F:\VS_Code_Project\XDRate-Emporer。
将这个独立副本改造成“帝王评分卡 / XDRate Emperor”，首期仅中国古代帝王。
不要修改 F:\VS_Code_Project\XDRate-Music 或其他兄弟仓库；不要自动重命名目录。

先完整阅读：
1. 当前适用的 AGENTS.md（如存在）及用户最新约束；
2. doc_CN/45_帝王评分双算法规范.md；
3. doc_CN/46_中国古代帝王评分卡开发计划.md；
4. design/emperor-card-ui.html 和 design/emperor-card-mobile.html；
5. 当前涉及的评分、存档、缓存、入口和卡片代码。

仅执行我点名的里程碑，先说明本轮范围，不擅自实施所有阶段。
先查 git status，保留已有 design/、scripts/download_all_emperors.py 和其他用户改动。
有冲突先停止相关写入并解释，不 reset/checkout 清理工作区。

核心规则：
- 算法 A 保留这个目录已有的自定义 LV 轴数值行为；当前代码是 music-linear-100-v4，
  不是其他会话音乐版的 v5，没有现成五心加分。普通轴 1–10，0=未评；
  LV0..LV6 对应 0、0.25、0.75、1、1.5、2.5、5；固定扣分仍按旧规则。
- 算法 B 严格保持用户公式：
  综合得分＝德×12%＋智×8%＋体×4%＋美×4%＋劳×5%＋雄心×5%＋尊严×8%
  ＋气量×5%＋欲望自控×6%＋人事管理×10%＋国力×15%＋民心×18%。
- 两种算法必须显式选择，算法选择不同于简易/专业/自定义编辑模式。
- 按 45 文档的已确认口径实施；若建议口径尚未确认，先列出需要确认的刻度、精度、
  缺项策略、默认算法，不在代码中静默决定。建议为 B 0–100、null=未评、0=真实零分，
  全 12 项齐全才产生正式总分，最多一位小数。
- B 的权重固定，总和 100%，不除以已评权重，不用普通均分；
  不叠加 A 的扣分、红心、等级权重，不修改公式来贴近旧输出。
- A/B 各存草稿，切换不自动换算、不覆盖；取消不修改输入、模式或评分。
- 默认不预填历史人物的分数、排名、评级或评语。

视觉：
- 宽屏按 design/emperor-card-ui.html 的名录—卡片—编辑器；
- 竖屏按 design/emperor-card-mobile.html 的名录、分组维度格+底部评分抽屉、生成分享；
- 采用宣纸、浓墨、朱砂、沉金和印章语汇，但优先文字可读与可操作；
- 手机稿三部手机只是展示板，不复制假刘海/状态栏和固定 390×800 外框；
- 两份稿的均分、缺评补 0 雷达、首次 ± 从 50 起跳等临时逻辑不进入正式实现；
- 姓名/朝代/年号/谥号/在位信息按人物稳定 ID 原子更新，不能只换头像留旧标签；
- 雷达必须有数值/条形替代，未评不伪装成真实零分；
- 个人签名档保留“（可选）”；界面主题独立于导出主题。

素材硬门禁：
- dist/皇帝 当前含原始画像与清单，是可能被 Vite 构建清理的位置；
  M0 素材保全和哈希校验完成前，不运行任何可能清理 dist 的构建命令。
- 不执行 scripts/download_all_emperors.py，不自动访问 B站补下载；
  不删除或覆盖原素材，先复制到稳定源素材目录并记录映射与哈希。
- 文件名中的“第N名”只是外部来源信息，不作为产品排名、人物 ID 或默认评价。
- 下载到的封面不等于公有领域；按真实来源和核验状态标注，未核验就用占位图。

数据与安全：
- 独立帝王领域/算法判别和 xdrate.emperor.* 存储空间；
  不清除、不覆盖 xdrate.music.*，不经旧音乐迁移器处理 B 的 0/null/小数。
- 音乐/游戏 JSON 默认报领域不兼容；有迁移需求时先保留原文件再另行设计。
- 卡片页脚与 JSON 写真实当前算法、版本与完整状态，不读固定的音乐全局算法常量。
- 预览/PNG 用同一正式卡片模型，所有外露比例真实解码和测尺寸；不造临时总分验证图替代。
- 原有 11 比例不能静默删除；新长卡 3:4.6 必须精确定义，不能冒充 3:4。
- 图片生成/下载是基础闭环；相册/分享按实际平台能力检测，失败或取消不能误报成功。
- 不以“界面示例已有按钮”为由承诺对比、排行榜、原生分享、云同步已经实现。

验证与交付：
- 按本目录 package.json 运行真实存在的命令，不引用音乐新版的门禁或测试数字。
- 新公式必须有精确测试、错误输入测试、算法切换/存档往返测试。
- UI 需真实浏览器测试，说明浏览器、宽度、键盘/触控、图片比例、失败项和未测平台。
- 不禁用文字对比度检测来取得通过；普通文字对比度目标至少 4.5:1，主体字号至少 14px。
- 不通过修改期望分数、删功能断言或盲目更新截图基线来掩盖缺陷。
- 最终列出文件改动、本轮完成项、实际测试结果、未完成项和下一阶段。
- 未经本轮明确授权，不提交 Git、不推送、不创建/更新 Toy、不提交审核。
  帝王发布目标尚未确定，绝不能上传到 XDRateMusic/XDRateGames。
```

## 四、遇到这些情况必须停下相关任务

- 未完成素材副本校验，却要求先跑构建；
- 需要改变用户原公式、让缺项自动归一化或重算旧评分；
- 目标素材存在同名不同哈希文件，或授权／人物身份判断不足；
- 要覆盖音乐缓存、迁移未确认的旧 JSON、使用已有音乐 Toy 身份；
- 需要用户未授权的外网下载、部署、推送、审核或资料批量改写。

可以继续无关的只读核查、纯算法测试和占位图下的开发，但必须明确阻塞范围，不能假报全部完成。
