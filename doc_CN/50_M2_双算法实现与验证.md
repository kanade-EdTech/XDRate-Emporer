# M2 双算法实现与验证

实现位置：`src/domain/emperor/workspace.ts`。

- `calculateFixedScores` 使用固定十二维百分比，以整数十分单位累加贡献。返回实际算法 ID、完成状态、完成维度数、权重覆盖、原始贡献小计、逐维明细和正式总分。未完成的正式总分为 null，真实 0 分参与完成度统计。
- `calculateCustomScores` 保持当前副本 v4 的 LV0–LV6、自定义轴和固定扣分数值行为；返回基础分、负扣分、总分、权重及逐轴贡献。无有效轴时不可计算。
- `calculateEmperorRecord` 按人物当前选择的算法计算对应草稿，不修改两份草稿。

验证命令：`node --experimental-strip-types --test scripts/emperor-workspace.test.mjs scripts/emperor-algorithm.test.mjs`。

10 项专项测试通过，覆盖存档基础、固定算法数学向量、12 个基向量、缺项、真实零分、非法数字/键/精度、切算法输入保留。自定义算法另以 200 组确定性输入对照当前真实 v4 实现，核对状态、总分及每轴贡献，全部一致。目标模块严格类型检查通过。Node 的 TypeScript 类型剥离属于实验功能，测试运行会输出相应提示。

本轮完成纯计算及验证，尚未接入 React 编辑器、人物名录或图片导出；没有将专项测试称为完整应用或浏览器验收。后续应将此计算结果直接接入界面与卡片模型，避免在组件中重新实现公式。
