# 前 100 名帝王完整名单补齐与检索修复记录

日期：2026-10-31。

## 一、问题原因排查（为何此前未看到“爱新觉罗玄烨”）

1. **名录主名称（`name`）格式不一致导致拼音排序错位**：
   - 界面左栏“帝王名录”按 `emp.name` 的汉语拼音排序（`Intl.Collator('zh-CN-u-co-pinyin')`）。
   - 第 26～100 名中的清代帝王（`爱新觉罗·胤禛`、`爱新觉罗·福临`、`爱新觉罗·颙琰`、`爱新觉罗·努尔哈赤`）及 `爱新觉罗·皇太极` 均以 `爱新觉罗·` 开头，排列在名录最顶部（A 组）。
   - 但此前前 25 名补充名录中，清圣祖（`qing-xuanye`）的 `name` 被写成了年号简称 `"康熙"`（排在 K 组），清高宗（`qing-hongli`）被写成了 `"乾隆"`（排在 Q 组），元世祖（`yuan-hubilie`）被写成了 `"忽必烈"`（排在 H 组）。因此用户在顶部 `爱新觉罗` 序列中查看时，看不到 `爱新觉罗·玄烨` 与 `爱新觉罗·弘历`。
2. **搜索框未忽略姓名间隔号（`·`）**：
   - 当用户在搜索框直接输入无间隔号的 `"爱新觉罗玄烨"` 时，原检索逻辑仅执行 `emp.fullName.toLowerCase().includes(q)`，而 `"爱新觉罗·玄烨".includes("爱新觉罗玄烨")` 因中间含有间隔号 `·` 返回 `false`，导致显示“没有找到匹配的人物”。
3. **本地 `localStorage` 旧缓存未同步规范姓名**：
   - 若浏览器本地已缓存早期版本的 `qing-xuanye`（`profile.name: "康熙"`），`loadInitialWorkspace()` 合并名录时未将旧简称更新为规范全名 `"爱新觉罗·玄烨"`。
4. **前 25 名未出场前列帝王名单校准**：
   - 对照《中国皇帝 258 排行榜》已发布的第 26～258 名（共 233 人），通过朝代排除法核对未出场的前 25 名完整名单：前秦除苻健（#37）、苻丕（#117）、苻登（#147）、苻生（#235）外，未出场的前列君主为**前秦世祖宣昭帝 `苻坚`**；北周除宇文毓（#82）外，未出场的前列君主为**北周太祖文帝 `宇文泰`** 与北周高祖武帝 `宇文邕`。
