# M1 帝王数据与存档契约执行记录

已实现 `src/domain/emperor/workspace.ts`，提供人物资料结构、两份算法草稿、固定维度常量、帝王存档解析／序列化和独立缓存适配。存档包含稳定人物 ID、朝代、庙号、谥号、年号、分段在位、身份和资料出处，人物信息允许暂为空。

固定草稿初始十二项全部为 null；自定义草稿采用十二个同名轴，初始 0（未评分）及 LV3。两份草稿独立保存理由和评价。尚未实现计算函数或连接编辑器。

解析器检查领域／版本、人物和轴 ID 唯一、选中人物存在、维度齐全、分值范围和精度、字数和集合上限。JSON 序列化拒绝 NaN/Infinity，避免它们自动变成 null。验证失败先抛出错误，缓存写入不会提前执行；只访问 `xdrate.emperor.workspace.v1`。

验证：Node 原生测试覆盖双草稿往返、零分/未评/小数、多人缓存隔离、非法导入不改变当前数据、保存失败不覆盖缓存、非有限值。运行命令：`node --experimental-strip-types --test scripts/emperor-workspace.test.mjs`。目标模块已单独通过 TypeScript strict 检查；完整应用依赖尚未安装，未运行全量应用检查或界面测试。
